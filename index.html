03 — Perfil

Ingeniería
y docencia

Llevo 16 años publicando código. Empecé con scripts de shell y PHP; hoy el grueso está en C# y .NET, con Python para datos y automatización. Ninguno de mis repositorios es un experimento descartable: cada uno responde a una necesidad real de un cliente o de mi propio stack.

Construyo software que otras personas pueden mantener sin llamarme.

Mi trabajo diario tiene dos mitades. De un lado, desarrollo software para empresas en Ecuador: sistemas de gestión, integraciones con ERP, herramientas internas que reemplazan hojas de cálculo y procesos manuales. De otro, enseño negocios digitales y TI: cómo se construye un sistema, cómo se modela una base de datos, cómo se automatiza un proceso con RPA.

Esa doble condición explica el contenido de este portafolio. Hay librerías de propósito general como DAL y DotNetCoords, que nacieron de un problema repetido. Hay frameworks completos como EthicalHacker Aurora, con 175+ módulos y base de datos de evidencias. Y hay herramientas de ofimática y escritorio —Folder Size Aurora, Aurora Optimizer— que resuelven el annoyance cotidiano de quien administra sistemas.

Mi regla de trabajo: lo que se automatiza se documenta. De los 31 repositorios propios, 26 tienen README con instalación, uso y límites. Y 8 de los 41 repos públicos son contribuciones a proyectos upstream —forks que existen porque ese código sirve a más gente que a mí.
